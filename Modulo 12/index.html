Unidades de medida en CSS

Aprendemos a utilizar diferentes unidades para diseñar páginas web.

Unidad PX

Los píxeles permiten establecer tamaños específicos.

Tamaño de 200 px

Unidad REM

Los rem se utilizan para definir tamaños relativos al tamaño de fuente del elemento raíz.

Texto de 2 rem

Unidad PORCENTAJE

El porcentaje permite establecer un tamaño relativo al elemento que contiene al objeto.

Ancho del 80 %
